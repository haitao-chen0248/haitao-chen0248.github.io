# School logos

One image per school, named after the entry `id` in `src/content/education.yaml`:

- `duke.png`, `hust.png`, `rice.png` (or `.svg`, `.jpg`, `.webp`): used in light mode
- `duke-white.png`, `hust-white.png`, ... (optional): white version used in dark mode

Transparent backgrounds work best; margins are fine but trimmed files look sharper.
Until a file is added, the school's short name (`abbr`) is shown instead.
